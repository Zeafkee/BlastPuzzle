# BlastPuzzle

A mobile collapse/blast puzzle game made with Unity 6. Tap groups of matching blocks, build rockets,
bombs and disco balls from big groups, break boxes, and finish the goals before you run out of moves.

![screenshots](Docs/screenshots.png)

**Play in the browser:** [zeafkee.github.io/play/blastpuzzle](https://zeafkee.github.io/play/blastpuzzle/) · **Android:** APK in [Releases](../../releases/latest)

## Features

- 20 levels with move limits, color goals and box goals; 1–3 stars per level
- Boosters: rocket (row/column), bomb (area), disco ball (one color), with chain reactions
- Obstacles: boxes and reinforced boxes
- Group-size icons that show which booster a group will create
- Deadlock detection with a deterministic, single-pass shuffle (no "shuffle until solvable" loop)
- Idle hints, goal fly-ins, squash-and-stretch falls, particles, screen shake
- Portrait UI for phones and tablets, safe-area aware, touch + mouse input
- Progress saved locally (Android and WebGL)

## Architecture

```
Assets/_Project/Scripts
├── Core/      Pure C# rules, no UnityEngine reference, unit tested
│              Board, Tile, GroupFinder, GravityResolver, Shuffler, BlastGame, AutoPlayer
├── Runtime/   Unity layer
│   ├── Gameplay/   GameController (one level), AppFlow (menu ⇄ level, popups)
│   ├── View/       BoardView, TileAnimator, TileViewPool, FxPlayer, BoardLayout
│   ├── UI/         HUD, menu, popups, safe area
│   ├── Data/       LevelData, LevelCatalog, TileTheme (ScriptableObjects)
│   └── Audio/ Save/ InputHandling/ App/
├── Editor/    Scene/asset generation, sprite import rules, level simulation, soak test
└── Tests/     EditMode tests for the rules
```

The rules resolve a whole turn instantly and describe it as a `TurnResult`; the view only plays that
description back. This keeps the rules testable without Play Mode, deterministic for a given seed,
and free of per-turn allocations.

- **[Docs/ARCHITECTURE.md](Docs/ARCHITECTURE.md)** — turn flow, algorithms and their complexity, design decisions
- **[Docs/PERFORMANCE.md](Docs/PERFORMANCE.md)** — what was optimized, how it was measured, what is still open

## Running it

1. Open the project with **Unity 6000.6** (URP 2D).
2. Open `Assets/_Project/Scenes/Main.unity` and press Play (Game view set to a portrait resolution).

Useful menu items under **BlastPuzzle**:

| Menu | What it does |
|---|---|
| Setup > Build Everything | Regenerates atlases, theme, levels, prefabs and the scene from code |
| Tools > Simulate Levels | Plays every level 300× with a bot and logs win rates |
| Tools > Soak Test | Bot plays levels back to back while frame time and allocations are recorded |
| Tools > Delete Save Data | Clears local progress |

Tests: `Window > General > Test Runner > EditMode`.

## Assets

All sprites and sounds are generated by scripts in this repo (`Tools/generate_sprites.py`,
`Tools/generate_audio.py`); nothing is taken from other games. Third-party: DOTween (Demigiant),
TextMesh Pro with Liberation Sans (SIL OFL).
